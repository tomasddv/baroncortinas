Cómo funciona: si elegís «Cadena → Metálica», el sistema suma solo los insumos asociados a esa elección. Para «Pared» y «Techo» podés cargar soportes diferentes. Si una opción no modifica el costo, no necesitás agregar una regla. No cargues el mismo soporte o cadena en la receta base y en estas reglas, porque se duplicaría el costo. Si cargás alguna regla de cadena para un modelo, se desactivan para ese modelo los antiguos adicionales fijos de cadena.
